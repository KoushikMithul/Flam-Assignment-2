📋 Setup Instructions

  1. Run the Android app on your emulator or device
  2. Set up port forwarding (for emulator only):
    adb forward tcp:8080 tcp:8080
  3. Click "Connect" button above to start streaming
  4. Toggle modes on the Android app to see different processing:
    • Raw Camera - Normal color feed
    • Canny Edge - White edges on black background
    • Grayscale - Black and white image
